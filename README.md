# MUSCLE QUEST

筋トレとランニングの記録で、自分の分身（男キャラクター）を育てるフィットネス育成アプリ。
鍛えた部位ごとに体が大きく・かっこよくなり、友達と記録を見せ合ってランキングで競える。

> 現在は MVP（操作できるプロトタイプ）。データは端末内（IndexedDB）に保存され、友達はモックデータ。

## 起動

```bash
npm install
npm run dev        # http://localhost:3000
npm test           # ドメインロジック・保存処理のテスト
npm run build      # 本番ビルド（型チェック込み）
```

スマホで確認する場合は、同じネットワーク上で `npm run dev -- -H 0.0.0.0` として PC の IP にアクセス。

## 構成

```

  xp.ts                    経験値・逓減・日次上限・レベル・推定1RM
  antiCheat.ts             入力検証（重量上限・ペース・日付・重複）
  character.ts             部位発達度・体脂肪感・進化段階・ストリーク
  ranking.ts / missions.ts ランキング指標・デイリーミッション
src/data/
  repository.ts            データアクセスのインターフェース
  local/                   IndexedDB 実装（MVP）
  mock/friends.ts          友達のモック（決定的に生成）
  hooks.ts                 画面用フック。getRepo() が実装の差し替えポイント
src/components/
  avatar/Avatar.tsx        部位パラメータで描く SVG キャラクター
supabase/migrations/     オンライン化用スキーマ（RLS込み）
tests/                   Vitest
```

## 育成ルール

- 筋トレ: 1セットの経験値 = `4 + √(重量×回数) × 0.9`。種目ごとの配分で部位に振り分け（例: ベンチプレス → 胸70% / 肩15% / 腕15%）。
- ラン: `距離 × 35`（+速いペースで最大30%ボーナス）。心肺75% / 脚25%。
- 部位の見た目は発達度 `1 - exp(-XP/1800)` で変化。ランは体脂肪を落とし、筋肉のカットが見えるようになる。
- レベル: Lv→Lv+1 に `100 + 50×(Lv-1)` XP。Lv5 細マッチョ / Lv12 マッチョ / Lv22 ゴリマッチョ / Lv35 レジェンド。
- 4日以上休むと見た目が少ししぼむ（経験値は減らない）。

## クエスト

- 7つのダンジョン（始まりの洞窟 → 胸・背中・脚・ラン・継続 → 覇王の城）。各階のボスに撃破条件がある。
- 条件は部位の経験値、推定1RM、連続日数、累計距離など「実際に鍛えた結果」。達成度に応じてボスのHPが減って見える。
- 挑戦時の判定は Repository が記録から再計算する（画面から渡した値は使わない）。クリアは `ダンジョン:階` で一意、順番の飛ばし不可。
- 踏破報酬は称号と装備アイテム。装備はキャラの見た目（ハチマキ・リストバンド・ベルト・ショーツ・シューズ・オーラ）に反映。全踏破で追加報酬。
- 定義は `src/domain/quests.ts` と `src/domain/items.ts`。

## キャラクター画像

- 主人公: `public/hero/{タイプ}_{段階}.webp`。段階はレベルで1〜6（ビギナー〜神話）、タイプはいちばん育った部位で8種類（`src/domain/character.ts` の `heroType`）。
  現在あるのはバランス型（1〜6）と胸型（2〜6）。ほかのタイプはバランス型で代わりに表示（`src/components/heroImages.ts` の `AVAILABLE` に足せば切り替わる）。
- 装備は体の画像に重ねて描く（`src/components/HeroFigure.tsx`）。頭・首・肩・手首・腰・裾・足の位置と、ショーツ・腰ゴム・靴の塗り替え用マスクは
  `python3 -I scripts/assets/hero_anchors.py` で体の画像から自動生成（`src/components/heroAnchors.json`, `public/hero/masks/`）。体の画像を追加・差し替えたら再実行する。
- アイテムは `src/domain/items.ts`（33個・9部位）。入手はボス撃破・ダンジョン踏破・レベル・最長連続日数。
- 装備アイコン: `public/items/{アイテムID}.webp`（ない場合は `ItemIcon` が自動で描く）。ボス: `public/bosses/*.webp`。
- 生成AIのシート画像からの切り出しは `scripts/assets/` のスクリプトで行う（`python3 -I scripts/assets/cut_hero_sheet.py シート.png 出力先 名前 人数`）。

## 不正・重複対策

- 記録IDはクライアント発行UUID。同じIDの再送信は無視（連打・通信リトライで二重計上しない）。
- 経験値台帳のIDは `種別:記録ID` で一意。1つの記録に経験値が2回付くことはない。
- 同じ種目を1日に6セット超で50%、10セット超で10%に逓減。ランは1日15km超を逓減。
- 1日の獲得上限 1,500XP。ランキングは上限・逓減適用後の値で集計。
- 種目ごとの重量上限、2'30"/km より速いペース、未来日付・8日以上前の記録は拒否。
- 自己ベストの大幅更新・1日50km超などは警告し、確認後のみ保存。
- オンライン化後は経験値計算をサーバー（Edge Function）だけで行い、クライアントから台帳に書き込めないよう RLS で制限する。
